# 🌱 Autonomous AI Farmer
### *Your Intelligent Digital Farm Manager*

A premium, full-stack multi-agent AI farming manager built with **Flask**, **SQLite**, **Google Gemini API**, and **ElevenLabs API**.

---

## 🛠️ Project Features

1. **Overview & Dashboard:** Clean, interactive dashboards visualizing farm health parameters, soil telemetry readings, priority alert warnings, and recent AI orchestrations.
2. **AI Agent Systems:** Seven specialized agents (Weather, Soil, Crop Disease, Irrigation, Fertilizer, Market, and the Farm Planning coordinator) analyzing telemetry inputs sequentially.
3. **Crop Leaf Image Analysis:** Upload photos of crop leaves directly into the AI diagnostics pipeline for real-time disease evaluations.
4. **Smart Alerts Registry:** Dynamic warning triggers mapping anomalous moisture, pH, and crop indicators directly to the dashboard.
5. **Farm Calendar:** Task schedule planner mapping action tasks manually or generated directly from AI recommendation plans.
6. **AI Farm Report:** Instantly download a professional compiled PDF summary of farm details, current readings, timeline records, and final planning coordinator reasoning.
7. **KisanMitra AI Chatbot:** Multilingual conversational assistant supporting voice playback, shopping list integration, and context-aware farm analysis.
8. **Settings Panel:** Control user profiles, security credentials, voice settings (ON/OFF, Auto Play, Voice selection), and manage Farm Quick Notes.

---

## 🏗️ Backend Architecture & Blueprint Routes

The application splits functionality into separate Flask Blueprint routes:

* `/` or `/home`: Public landing pages.
* `/signin` & `/signup`: Password-hashed session authentication handlers.
* `/overview` & `/dashboard`: Farm health logs and telemetry indicator grids.
* `/farm`: Profile configs and telemetry daily logger.
* `/agents`: Analysis trigger controls for specialized agents.
* `/crop-analysis`: Multimodal vision file uploads for leaf evaluations.
* `/recommendations`: Completed log list of priority recommendations.
* `/alerts`: List and mark-read handlers for critical alerts.
* `/memory`: Longitudinal timeline history of coordinator plans.
* `/calendar`: CRUD actions for scheduled maintenance tasks.
* `/report`: Instantly compile and download ReportLab PDF summaries.
* `/settings`: Profile, Security, Preference, and Quick Notes checklists.
* `/api/chat`: Chat history retrieval and messaging hooks for KisanMitra.

## 💾 Database Schema

The SQLite database file (`instance/autonomous_farmer.db`) manages:
* **users:** Logged-in profile, language preferences, and password hashes.
* **farms:** Specifications regarding acreage, irrigation types, and soil methods.
* **crops:** Currently registered varieties and crop development stages.
* **observations:** Daily telemetry readings log (humidity, pH, N-P-K, health index).
* **agent_runs:** Output logs and diagnostic statuses from AI runs.
* **recommendations:** Actions lists generated by agent evaluations.
* **alerts:** High/Medium/Low warnings raised by telemetry thresholds.
* **farm_tasks:** Complete/delete checklist calendar agenda items.
* **quick_notes:** Personal checklist shopping items for fertilizer or seeds.
* **chat_messages:** Conversations with KisanMitra AI.

## 🚀 Installation & Run Guide

### 1. Set Up Virtual Environment

Open your terminal in the project root:

```bash
# Create a virtual environment
python -m venv .venv

# Activate it (Windows)
.venv\Scripts\activate

# Activate it (macOS/Linux)
source .venv/bin/activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Create a `.env` file in the root directory:

```env
SECRET_KEY=your_secure_flask_secret_key
GEMINI_API_KEY=your_google_gemini_api_key
ELEVENLABS_API_KEY=your_elevenlabs_api_key
ELEVENLABS_VOICE_ID=your_elevenlabs_voice_id
ELEVENLABS_MODEL_ID=eleven_monolingual_v1
```

### 4. Run the Application

```bash
python app.py
```

The database file initializes automatically if missing, and the local dev server starts listening on [http://localhost:5000/](http://localhost:5000/).
